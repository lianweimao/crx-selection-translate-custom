全文翻译并发

全文翻译会把页面文本分批并发发送给翻译服务。并发越高速度越快，但可能触发翻译接口的限流；建议 4–8。

GitHub 同步

需要一个 GitHub Personal Access Token（细粒度令牌，仅授予目标仓库的 Contents: Read and write 权限）。 出于安全考虑，只支持私有仓库：公开仓库会把你的配置历史暴露给所有人。

本地备份

导出的 JSON 不包含 GitHub Token，可以安全地备份到本地。

同步范围

同步 chrome.storage.local 中的全部配置项（翻译服务、快捷键、全文翻译样式等）， 自动排除：GitHub Token、同步记录、全文翻译次数计数和扩展内部状态。 下载配置后，已打开的页面建议刷新一次；部分设置需要重新加载扩展才能完全生效。
